# Understanding-Dataset-Datatypes
# AI & ML Internship Task 1

## Title
Understanding Dataset and Data Types

---

## Objective
The objective of this task is to understand the dataset structure, identify different data types, and perform basic exploratory data analysis using Python libraries like Pandas and NumPy.

---

## Tools and Technologies Used
- Python
- Pandas
- NumPy
- Google Colab
- GitHub

---

## Dataset Used
Titanic Dataset

Dataset contains passenger information such as:
- Passenger ID
- Name
- Age
- Gender
- Ticket
- Fare
- Cabin
- Survival Status

---

## Tasks Performed

### 1. Loaded Dataset
Used Pandas to load the Titanic CSV dataset.

### 2. Explored Dataset Structure
Used:
- head()
- shape
- info()

to understand rows, columns, and data types.

### 3. Identified Data Types
Separated:
- Numerical Columns
- Categorical Columns

### 4. Statistical Analysis
Used describe() to analyze numerical data.

### 5. Checked Missing Values
Used isnull().sum() to identify null values.

### 6. Identified Unique Values
Checked unique values in categorical columns.

---

## Observations

- Dataset contains both numerical and categorical data.
- Missing values are present in Age, Cabin, and Embarked columns.
- Numerical columns include:
  - Age
  - Fare
  - PassengerId

- Categorical columns include:
  - Name
  - Sex
  - Ticket
  - Cabin
